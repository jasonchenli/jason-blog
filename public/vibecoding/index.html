Modern Tech Stack

Built with cutting-edge technologies for performance and scalability.

Frontend

  • React Router 7.9 - Full-stack framework with SSR
  • TypeScript 5.9 - Type-safe development
  • TailwindCSS 4.1 - Utility-first CSS
  • ECharts 5.6 - Professional data visualization
  • PWA with Service Worker - Offline support

Backend

  • FastAPI - High-performance Python API
  • PostgreSQL - Robust relational database
  • Redis - Caching and session management
  • Dify AI - Workflow for NL2SQL queries
  • MinIO/S3 - File storage solution
